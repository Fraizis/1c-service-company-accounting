  зарплаты в малом предприятии.

  - Справочники: Номенклатура, Склады, ВариантыНоменклатуры, ВидыГрафиковРаботы
  - Документы: ПриходнаяНакладная, ОказаниеУслуги, НачисленияСотрудникам
  - Регистры накопления, сведений, бухгалтерии и расчёта
  - План счетов с субконто, планы видов характеристик
  - 12 отчётов на запросах и СКД
  - 5 ролей, подсистемы, регламентные задания
